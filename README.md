# Spark

极简 Linux 桌面速记工具 —— 快速捕获，不打断心流。

## 使用

| 快捷键       | 功能                           |
| ------------ | ------------------------------ |
| `Alt+Q`      | 唤出速记窗口                   |
| `Ctrl+Alt+Q` | 唤出历史记录窗口               |
| `Tab`        | 增加列表嵌套层级               |
| `Shift+Tab`  | 减少列表嵌套层级               |
| `Enter`      | 换行；列表项上自动续行并补标记 |
| `Ctrl+Enter` | 保存并收起                     |
| `F11`        | 全屏 / 退出全屏                |
| `Esc`        | 退出全屏或收起窗口，保留草稿   |

### 速记窗口

- 编辑器基于 CodeMirror 6，底层仍是纯文本，可随时修改或删除列表标记
- 只解析列表层级：无序列表、有序列表，按行首缩进区分嵌套
- 标题、引用、代码块、分割线、行内格式等 Markdown 语法按普通文本显示
- 输入 `- ` / `* ` / `+ ` 后实时显示为圆点
- `Tab` / `Shift+Tab` 调整当前行或选中多行的层级；已无缩进时取消列表标记
- `Enter` 在列表项上自动续行并补 `- `；空列表项按 `Enter` 退出当前层级
- 顶部实时显示字数与行数
- `Ctrl+Enter` 或「保存」按钮保存并收起，成功后短暂提示「已保存」
- 空内容保存时直接收起，不写入记录
- 草稿自动存入 localStorage，`Esc`、点击窗口外、退出应用都不会丢失
- 无边框窗口：顶栏可拖动，右 / 下 / 右下角可缩放

### 历史记录窗口

- 记录按最新在前排列，卡片内直接渲染列表层级
- 顶部搜索框本地过滤，不请求后端
- 时间筛选：全部 / 今天 / 近 7 天 / 近 30 天，可与搜索叠加
- 悬停卡片显示操作图标：复制 / 编辑 / 删除
- 编辑为整窗浮层，交互与速记编辑器一致，`Ctrl+Enter` 保存、`Esc` 取消
- 点「选择」进入多选模式，勾选卡片后可批量操作：
  - 复制原始文本：按列表顺序拼接，不带时间戳与列表标记
  - 导出图片：按当前列表排版绘制为 PNG，通过系统对话框选择保存位置
  - 删除：需再点一次「确认删除」（3 秒内有效），避免误操作
  - 多选模式下 `Esc` 先退出选择，再按一次才关闭窗口
- 刚保存的记录会短暂高亮
- 每次唤起或重新聚焦自动刷新；`Esc` 或 `✕` 关闭（不退出应用）

### 通用行为

- 再次按快捷键：速记窗口重新聚焦；历史窗口在显示 / 隐藏间切换
- 关闭窗口 = 隐藏，应用常驻后台
- 托盘菜单：显示窗口 / 历史记录 / 设置 / 退出；左键点托盘也可切换速记窗口
- 单实例运行：重复启动会唤起已有窗口后退出

### 设置（历史窗口 ⚙ 或托盘 → 设置）

- **主题**：白天 / 黑夜 / 跟随系统三档，切换后三个窗口即时生效；跟随系统时随桌面明暗自动变化
- **开机自启**：登录后自动运行（Linux 写 `~/.config/autostart/spark.desktop`）
- **笔记保存位置**：自定义 `notes.jsonl` 路径；可随时重置为默认
- **数据**：导出 / 导入 JSONL 备份；导入与现有笔记合并并按 `time + content` 去重，写入前自动 `.bak`
- **快捷键**：点击输入框后直接按下组合键即可录制；X11 下立即生效，Wayland 受 Portal 限制需重启
  - `Esc` 取消录制，`Backspace` 恢复默认值
  - 录制期间会临时注销全局快捷键，避免按下组合键时弹出窗口打断
- **检查更新**：「关于」显示当前版本，可手动检查；发现新版本时展示更新说明摘要与「下载新版」按钮，跳转 GitHub Release
  - 启动后每天最多自动检查一次，托盘菜单会同步显示「发现新版本 vX.Y.Z」
- 所有偏好持久化在 `~/.local/share/spark/settings.json`（原子替换写回）

## 数据

笔记追加保存在 `~/.local/share/spark/notes.jsonl`（JSON Lines，每行 `{"time": ..., "content": ...}`）；自定义路径则在设置中所选的位置。

编辑与删除通过临时文件 + 原子替换写回，避免损坏数据；改写前会把上一版备份为 `notes.jsonl.bak`。换行等特殊字符由 JSON 转义，每条记录始终单行。

设置窗口「数据」可手动备份与恢复：

- 导出：把当前笔记文件逐字节复制为 `spark-notes-YYYYMMDD.jsonl`，可完整还原
- 导入：选择 JSONL 备份，与现有笔记合并；按 `time + content` 去重，坏行跳过，写入前自动生成 `.bak`；导入后历史窗口自动刷新

未保存的草稿存在 WebView 的 localStorage 中，与笔记文件分开。

## 开发

```bash
npm install
npm run tauri dev     # 开发运行
npm run tauri build   # 产出安装包
```

要求：Rust、Node.js、以及 Tauri v2 Linux 依赖（webkit2gtk-4.1、gtk3、libayatana-appindicator3-dev 等）。

## 架构

- **三个窗口**：速记（`main`，400×450，可缩放）、历史（`history`，520×560，可缩放）、设置（`settings`，460×480，固定尺寸）；均无边框 / 置顶 / 不进任务栏，启动即隐藏
- **前端模块**：`src/editor/` 负责 CodeMirror 装配、逐行装饰与主题；`src/markdown/` 存放编辑器与历史预览共用的列表层级规则；`src/theme.js` 负责主题解析与跨窗口同步
- **主题**：偏好写入 `settings.json`，切换后通过 Tauri 事件广播；系统模式使用 `prefers-color-scheme` 检测
- **全局快捷键**：`tauri-plugin-desktop-integration` 统一注册 —— X11 直接 grab，Wayland 走 XDG Portal（首次绑定会弹系统授权对话框，属正常现象）。注：Wayland Portal 路径目前仅支持单个快捷键会话，双快捷键在 X11 下完整可用
- **版本更新**：`src-tauri/src/update.rs` 查询 GitHub 最新 Release，版本比较与解析为纯函数；结果缓存在 `settings.json`，启动检查 24 小时节流，下载页由 `tauri-plugin-opener` 打开
- **窗口定位**：速记窗口显示时定位到鼠标附近（多显示器下 clamp 到所在显示器），失败回退居中
- **失焦行为**：速记窗口点击外部自动收起（250ms 防抖 + 边缘安全边距，避免缩放时误收起）；历史与设置窗口不自动收起
- **常驻后台**：拦截 `CloseRequested` 改为隐藏；single-instance 防双开；托盘提供退出入口
- **中文输入**：监听 `isComposing`，输入法选词不会误触发操作
- 修改默认快捷键：`src-tauri/src/config.rs` 顶部的 `HOTKEY_MAIN` / `HOTKEY_HISTORY` 常量

仅支持 Linux（X11 / Wayland）。
